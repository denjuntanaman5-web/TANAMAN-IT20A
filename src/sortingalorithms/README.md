Sorting Algorithms in Java
Program Description

Kini nga Java program nagpakita kung giunsa paghan-ay ang mga numero gamit ang tulo ka sorting algorithms: Bubble Sort, Selection Sort, ug Insertion Sort.

Ang program adunay original array nga adunay lain-laing numero. Maghimo kini og kopya sa array para magamit sa matag sorting algorithm nga dili mausab ang original array. Sa katapusan, ipakita niini ang resulta sa matag sorting algorithm gikan sa pinakagamay hangtod sa pinakadako nga numero.

Bubble Sort

Ang Bubble Sort nagtrabaho pinaagi sa pagtandi sa duha ka magkatapad nga numero. Kung ang unang numero mas dako kaysa ikaduha, mag-ilis sila og pwesto. Balikon kini hangtod nga mahan-ay ang tanang numero.

Selection Sort

Ang Selection Sort mangita sa pinakagamay nga numero sa array ug ibutang kini sa unang hustong posisyon. Padayonon kini nga proseso hangtod mahan-ay ang tanang numero.

Insertion Sort

Ang Insertion Sort mokuha og usa ka numero ug ibutang kini sa hustong lugar taliwala sa mga numero nga nauna nang na-sort. Kung naay mas dako nga numero, ibalhin kini aron makahatag og lugar.

Differences Between the Three Sorting Algorithms
Bubble Sort – Nagtandi sa magkatapad nga numero ug mag-ilis sa ilang pwesto.
Selection Sort – Mangita sa pinakagamay nga numero ug ibutang kini sa hustong posisyon.
Insertion Sort – Mokuha og numero ug isulod kini sa hustong lugar.

Nagkalahi sila sa pamaagi pero pareho ang ilang tumong nga mahan-ay ang mga numero gikan sa gamay ngadto sa dako.

Reflection Questions and Answers
1. How does each sorting algorithm arrange numbers? What makes their processes different?

Ang Bubble Sort magtandi sa magkatapad nga numero. Ang Selection Sort mangita sa pinakagamay nga numero. Ang Insertion Sort mokuha og numero ug ibutang kini sa hustong lugar. Lahi sila sa ilang pamaagi sa paghan-ay sa mga numero.

2. Among the three sorting algorithms, which one do you think is the easiest to understand and implement? Why?

Para nako, ang Bubble Sort ang pinakasayon sabton kay simple ra ang proseso niini. Itandi lang ang duha ka magkatapad nga numero ug ilisan ang ilang pwesto kung kinahanglan.

3. If the numbers are already sorted, which algorithm do you think would perform better? Explain your answer based on how the algorithms work.

Para nako, ang Bubble Sort ang mas maayo kung sorted na daan ang mga numero. Tungod kay naa kini'y swapped variable, kung walay nausab nga numero, mohunong dayon ang program ug dili na magpadayon sa ubang balik.

4. What will happen if you add more numbers to your array? How might this affect the performance of each sorting algorithm?

Kung magdugang ko og daghang numero, mas modaghan ang trabaho sa matag algorithm. Mas daghan silang numero nga kinahanglan itandi, pangitaon, ug ibalhin. Tungod niini, mahimong mas dugay mahuman ang pag-sort.

5. As a future programmer, why is it important to understand different sorting algorithms instead of using just one?

Isip future programmer, importante nga masabtan nako ang lain-laing sorting algorithms kay dili parehas ang ilang performance. Makatabang kini nako sa pagpili sa pinakamaayong algorithm depende sa sitwasyon ug sa gidaghanon sa mga numero nga akong i-sort.
